Win                  —  app menu
Win + Enter          —  terminal
Win + E              —  file manager
Win + B              —  browser
Win + G              —  GeOS Centre
Win + I              —  settings
Win + Q  /  Alt + F4 —  close window
Win + F              —  fullscreen
Win + T              —  make window floating
Win + J              —  rotate window layout
Win + arrows         —  move focus to neighbor window
Win + Shift + arrows —  move window
Win + 1…9            —  desktop 1…9
Win + Shift + 1…9    —  move window to desktop
Win + Tab            —  next desktop
Win + mouse          —  move (left) / resize (right)
Win + V              —  clipboard history
Win + Shift + S      —  screenshot of an area
Win + Space          —  switch keyboard layout
Win + O              —  glass windows on/off
Win + L              —  lock
Win + X              —  power and log out
Ctrl + Shift + Esc   —  task manager
Three fingers on touchpad — switch desktop
