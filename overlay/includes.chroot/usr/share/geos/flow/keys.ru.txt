Win                  —  меню приложений
Win + Enter          —  терминал
Win + E              —  проводник
Win + B              —  браузер
Win + G              —  Центр GeOS
Win + I              —  параметры
Win + Q  /  Alt + F4 —  закрыть окно
Win + F              —  на весь экран
Win + T              —  сделать окно плавающим
Win + J              —  повернуть раскладку окон
Win + стрелки        —  перейти к соседнему окну
Win + Shift + стрелки — передвинуть окно
Win + 1…9            —  рабочий стол 1…9
Win + Shift + 1…9    —  перенести окно на рабочий стол
Win + Tab            —  следующий рабочий стол
Win + мышь           —  двигать (левая) / менять размер (правая)
Win + V              —  история буфера обмена
Win + Shift + S      —  снимок области экрана
Win + Space          —  сменить раскладку
Win + O              —  стеклянные окна вкл/выкл
Win + L              —  заблокировать
Win + X              —  выключение и выход
Ctrl + Shift + Esc   —  диспетчер задач
